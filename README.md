# 🎮 jogo-de-adivinhação

Jogo de adivinhação de número desenvolvido em **Python**, onde o computador gera um número aleatório e o jogador tenta adivinhar com dicas de "maior" ou "menor".

---

## 📋 Sobre o Projeto

Este repositório contém o código-fonte de um jogo interativo de adivinhação criado em Python. O programa gera um número aleatório entre 1 e 100, e o jogador recebe dicas a cada tentativa até acertar o número.

## 🚀 Como Executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/MIcodebot/jogo-de-adivinha-o.git
   ```
2. Execute o jogo:
   ```bash
   python jogo.py
   ```
3. Digite números para tentar adivinhar. O jogo indicará se o número é maior ou menor!

---

## 🎯 Como Jogar

1. O computador escolhe um número secreto entre **1 e 100**
2. Você digita um número na tela
3. O jogo informa se o número secreto é **maior** ou **menor**
4. Continue tentando até acertar!
5. O jogo conta o número de tentativas
